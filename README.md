# KiwiOT 优智云家智能门锁集成

这是一个用于 Home Assistant 的 KiwiOT/优智云家智能门锁自定义集成。通过 Kiwik 云端服务连接设备（不是纯局域网集成），提供门锁状态、事件、用户信息、图片和远程开锁确认功能。

## 功能特点
- Home Assistant 原生 `lock` 实体显示最近已知的上锁/解锁状态
- 实时监听门锁事件，并触发 `kiwiot_ws_event` HA 事件供自动化使用
- 支持多种开锁方式识别、用户信息和事件图片预览
- 远程开锁采用现有的 MFA/密码确认流程；原生 lock 实体仅展示状态，不提供绕过确认的直接开锁操作
- 可从 HA 下载诊断信息；账号、密码、Client ID 和令牌字段会脱敏

## 安装

### HACS
1. 在 HACS 的自定义仓库中添加本仓库地址，类别选择“集成”。
2. 搜索并安装 `KiwiOT`。
3. 重启 Home Assistant。

### 手动安装
将 `custom_components/kiwiot_ws` 目录复制到 HA 配置目录下的 `custom_components/kiwiot_ws`，然后重启 Home Assistant。

## 配置
在“设置 → 设备与服务 → 添加集成”中搜索 KiwiOT，填写平台注册账号、密码和 Client ID。不要在日志、Issue 或截图中公开这些凭据。SSL 验证默认应保持启用；只有排障时才考虑关闭验证。

## 实体与事件
- `lock.*`：最近已知的锁态，只有明确的 LOCKED/UNLOCKED 类事件会改变状态；报警或未知事件不会伪装成锁态变化。
- `sensor.*`：门锁事件、家庭/设备和用户相关信息；如果云端设备详情或事件提供有效的 0–100 电量值，会创建 `sensor.<设备名>_battery`（device class: battery）。
- `camera.*`：支持的事件图片预览。
- `text.*` / `button.*`：现有 MFA 远程开锁确认流程。
- 自动化可监听 `kiwiot_ws_event`，事件数据包括设备 ID、事件名、显示标签、级别、时间和事件数据。事件数据可能包含个人信息，请谨慎配置自动化日志和通知。

已知事件标签包括开锁、上锁、门内按键/把手开锁、用户变更、密码/指纹/门卡错误、指纹冻结、防撬、低电量、门未关及人员徘徊。未知服务端事件会保留原始事件名并继续发布，锁态保持不变。电量传感器仅接受明确的 battery/battery_level/battery_percent 等字段以及 0–100 数值；若当前设备或服务端不提供这类字段，实体会显示“未知”，而不是猜测百分比。首次读取尝试来自设备列表、设备详情和历史事件，之后由 WebSocket 事件更新。

## 诊断与排错
在集成页面选择“下载诊断信息”可查看连接和设备摘要。诊断会主动遮蔽账号、密码、Client ID、Access/Refresh Token 和开锁数据；分享诊断前仍请检查 HA 日志及图片链接是否含个人信息。

若登录失败，确认账号可正常登录优智云家网页、Client ID 有效且系统时间正确。若事件中断，检查 HA 到 Kiwik 云服务的网络连通性，并查看集成日志中的连接/重连信息。此集成依赖云服务可用，不承诺本地离线控制。

## 开发与测试
- 事件映射单元测试：`python -m unittest test_event_utils.py`
- 当前测试覆盖锁态判定、事件名归一化、已知标签、未知事件回退以及嵌套电量字段提取和无效电量过滤。
- 发布前建议在目标 Home Assistant 版本上运行 `hassfest`，并用真实集成配置验证登录、WebSocket 事件、设备重启后的恢复及远程开锁确认流程。

## Home Assistant 兼容性
本仓库尚未声明完整的 Home Assistant 版本支持矩阵。当前代码使用现代 ConfigEntry 平台转发 API；合并或发布前应至少在维护者声明的最低版本和当前稳定版上运行 hassfest 与集成测试。未经验证的版本不应在 README 中承诺兼容。

## 安全说明
远程开锁属于高风险操作。保留 MFA 确认流程；不要将开锁自动化暴露给未受信任用户，也不要把凭据、令牌、开锁数据或含个人信息的门锁事件发布到公开 MQTT/日志系统。
